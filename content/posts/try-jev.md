jevってツールがたいへん話題なので試してみた。

## jevの試し方

{{< linkcard "https://typesafe.ai/" >}}

公式ページに行くと、右上に「Join Waitlist」というボタンがある。それを押すとメールアドレスを入れるダイアログがあるのでメールアドレスを入れる。しばらく待っているとメールが届くので、メールに含まれているリンクから色々手続きすると色々 (API キーとか) 使えるようになる。自分の場合は数時間でメールがきた。

typesafe.ai にログインすると、ログインした先のページには Claude Code などの AI エージェントに読み込ませてプラグインをインストールするためのプロンプトが用意されている。大変用意がいい。Claude Code にコピペして食わせてみたところ、サクッと使える状態になった。

## 何ができるんだこれは

jev の使い方としては、まず LLM を使うのと同じように自然言語で質問を投げかけて使う。が、jev は通常の LLM と違ってテキストを出力することができない。その代わり、問いに対して、こちらが提示した選択肢のどれにどの程度合致するか、みたいのを返すことができる。そんで通常のテキストが出力できない代わりにとても高速で (500ms くらいで返事がくる) 、そんで安い。出力無料ですって。出力無料ってほんまか。

たとえば「この記事のジャンルは？」って質問して、返事は AI、ポエム、プログラミング、天気、政治、のどれかにしてね、みたいな感じに選択肢を与える。するとそれぞれ自信度みたいな数値が0~1で返ってくる。この記事だったら、AI 0.9、ポエム 0.5、プログラミング 0.8、天気 0.2、政治 0.1、みたいな感じになるんだろう (値は適当) 。

サインインした直後から、$5 のクレジットが付与されている。AI を扱うっていうのに $5 じゃ瞬溶けしちゃうんじゃないのって思うかもしれないが、jev は大変安いので $5 でもまあまあ遊べる。
